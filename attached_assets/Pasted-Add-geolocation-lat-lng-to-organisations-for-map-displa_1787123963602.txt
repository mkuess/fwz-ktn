STEP 3 - Create a Geocoding service:
Create app/Services/GeocodingService.php

<?php
namespace App\Services;

class GeocodingService
{
    public function geocode(string $address): ?array
    {
        $encoded = urlencode($address);
        $url = "https://nominatim.openstreetmap.org/search?q={$encoded}&format=json&limit=1&countrycodes=at";
        
        $context = stream_context_create([
            'http' => [
                'header' => "User-Agent: FWZ-Kaernten/1.0 (info@fwz-ktn.at)\r\n",
                'timeout' => 5,
            ]
        ]);
        
        $response = @file_get_contents($url, false, $context);
        if (!$response) return null;
        
        $data = json_decode($response, true);
        if (empty($data)) return null;
        
        return [
            'latitude' => (float) $data[0]['lat'],
            'longitude' => (float) $data[0]['lon'],
        ];
    }
    
    public function geocodeOrganisation(Organisation $organisation): bool
    {
        $parts = array_filter([
            $organisation->street,
            $organisation->zip,
            $organisation->city,
            'Kärnten',
            'Österreich',
        ]);
        
        if (empty($organisation->city) && empty($organisation->zip)) return false;
        
        $address = implode(', ', $parts);
        $result = $this->geocode($address);
        
        if (!$result) return false;
        
        $organisation->updateQuietly([
            'latitude' => $result['latitude'],
            'longitude' => $result['longitude'],
            'geocoded_at' => now(),
        ]);
        
        return true;
    }
}

Add use App\Models\Organisation; at the top of the service.

STEP 4 - Add geocode bulk action to OrganisationResource:
In app/Filament/Resources/OrganisationResource.php add to bulkActions:

BulkAction::make('geocode')
    ->label('Standort ermitteln')
    ->icon('heroicon-o-map-pin')
    ->color('info')
    ->requiresConfirmation()
    ->modalHeading('Standorte ermitteln')
    ->modalDescription('Für alle ausgewählten Organisationen wird der Standort über die Adresse ermittelt und gespeichert (OpenStreetMap Nominatim). Dies kann einige Sekunden dauern.')
    ->action(function (Collection $records): void {
        $service = new \App\Services\GeocodingService();
        $success = 0;
        $failed = 0;
        
        foreach ($records as $record) {
            // Small delay to respect Nominatim rate limit (1 req/sec)
            usleep(1100000);
            
            if ($service->geocodeOrganisation($record)) {
                $success++;
            } else {
                $failed++;
            }
        }
        
        \Filament\Notifications\Notification::make()
            ->title("Standorte ermittelt: {$success} erfolgreich, {$failed} fehlgeschlagen")
            ->success()
            ->send();
    })
    ->deselectRecordsAfterCompletion(),

STEP 6 - Auto-geocode when saving an organisation without coordinates:
In OrganisationResource in the after-save hook, OR in the Organisation model boot():

In Organisation model add to boot():
static::saved(function (Organisation $organisation) {
    if (is_null($organisation->latitude) && 
        (!empty($organisation->city) || !empty($organisation->zip))) {
        
        dispatch(function () use ($organisation) {
            $service = new \App\Services\GeocodingService();
            $service->geocodeOrganisation($organisation);
        })->afterResponse();
    }
});

This geocodes automatically after saving if no coordinates exist yet and an address is present.
