Create a public benefits overview page and link the "Alle Benefits" button to it. Do NOT delete the database.

STEP 1 - Create BenefitController:
app/Http/Controllers/BenefitController.php

public function index() {
    $benefits = \App\Models\Benefit::where('is_active', true)
        ->orderBy('sort_order')
        ->orderBy('name')
        ->get();
    return view('benefits.index', compact('benefits'));
}

STEP 2 - Add route in routes/web.php:
Route::get('/benefits', [BenefitController::class, 'index'])->name('benefits.index');
