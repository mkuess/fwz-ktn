Fix two bugs in /mitglied-werden form. Do NOT delete the database.

BUG 1 - Tom Select dropdown overlaps other fields:
The dropdown z-index is too low or the form layout causes it to render behind other elements.

Fix by adding CSS:
.ts-dropdown {
    z-index: 9999 !important;
    position: absolute !important;
}

Also make sure the organisation field container has position: relative:
#organisation_id + .ts-wrapper {
    position: relative;
}
