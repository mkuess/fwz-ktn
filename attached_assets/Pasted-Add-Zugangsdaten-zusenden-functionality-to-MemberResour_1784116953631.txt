STEP 3 - Add membership_number auto-generation:
When a member's status is set to 'approved' and membership_number is empty, auto-generate:
Format: FWZ-YYYY-XXXXXX (e.g. FWZ-2026-000042)
In Member model add a method:
public function generateMembershipNumber(): string
{
    $year = now()->year;
    $padded = str_pad($this->id, 6, '0', STR_PAD_LEFT);
    return "FWZ-{$year}-{$padded}";
}

STEP 4 - Add a custom Action to MemberResource edit page header:
In app/Filament/Resources/MemberResource/Pages/EditMember.php add to getHeaderActions():

Action::make('sendActivation')
    ->label('Zugangsdaten zusenden')
    ->icon('heroicon-o-envelope')
    ->color('success')
    ->visible(fn () => $this->record->status === 'approved')
    ->requiresConfirmation()
    ->modalHeading('Zugangsdaten zusenden')
    ->modalDescription('Es wird ein Aktivierungslink an ' . ($this->record->email ?? '') . ' gesendet. Das Mitglied kann damit ein Passwort erstellen und sich einloggen.')
    ->action(function () {
        $member = $this->record;
        
        // Generate membership number if not set
        if (empty($member->membership_number)) {
            $member->membership_number = $member->generateMembershipNumber();
        }
        
        // Generate activation token
        $token = \Illuminate\Support\Str::random(64);
        
        // Save
        $member->update([
            'activation_token' => $token,
            'activation_sent_at' => now(),
            'membership_number' => $member->membership_number,
        ]);
        
        // For now: show the activation link in a notification (email will be added later)
        $activationUrl = url('/aktivierung/' . $token);
        
        \Filament\Notifications\Notification::make()
            ->title('Aktivierungslink generiert')
            ->body('Link: ' . $activationUrl . ' | Mitgliedsnummer: ' . $member->membership_number)
            ->success()
            ->persistent()
            ->send();
    }),
